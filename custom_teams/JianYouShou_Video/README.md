## 恢复来源

2026-11-03 纳入版本管理时，原先未被跟踪的 `downloads/iuno_jianxin_shore_video_rotation` 目录及 1.0.3 ZIP 已不在工作树中。本目录以保留下来的 1.0.2 导入包为基础，重放本会话交付 1.0.3 时的补丁：有限窗口交替 E/普攻，撤掉月弓 E 冷却确认的硬性推进条件，并更新版本标记。1.0.3 原 ZIP 不在磁盘，未声称逐字节比对过原交付包。

此次仅恢复、保存源码及配套验证，不继续修改轮转行为。完整视频、个人日志和配置不纳入仓库；生成 ZIP 输出到已忽略的 `dist/`。

## 构建和导入

在仓库根目录使用本地 Python 环境运行；没有 `.venv` 时可用 `python`：

```powershell
.\.venv\Scripts\python.exe custom_teams/JianYouShou_Video/build.py
```

构建只依赖标准库，输出 `dist/JianYouShou_Video_Codex_1.0.3.zip`，可用 `--output <路径.zip>` 指定位置。ZIP 根目录严格包含 `team.json` 和三个角色文件，不包含文档、构建脚本或测试。

暂停自动战斗，导入 ZIP 并确认“生效代码：导入代码”、版本 `1.0.3`，开启共鸣解放后开始新一场战斗。
